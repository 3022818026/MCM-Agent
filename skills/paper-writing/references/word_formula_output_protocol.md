## 一、固定输出顺序

生成数学建模论文内容时，每个独立公式必须依次给出：

1. 公式前的正文说明；
2. 单独排版的显式公式；
3. 标题“Word公式框输入代码”；
4. 一个只含一整行LaTeX输入的代码块。

示例：

设作物i的价格下限和价格上限分别为Pᵢᴸ和Pᵢᵁ，则基准销售价格取价格区间的中点：

\[
P_i=\frac{P_i^L+P_i^U}{2}.
\]

Word公式框输入代码：

```latex
P_i=\frac{P_i^L+P_i^U}{2}
```

代码行不得包含换行、`\[`、`\]`、`$`或`$$`。代码块的语言标签不属于公式内容，不得把“latex”一词复制进公式。

## 二、正文中的简单符号

混杂在文字中的简单符号直接使用正常显示形式，不单独附加LaTeX代码。例如：

> 其中，xₜₗₛᵢ表示第t年地块l在第s季种植作物i的面积，yₜₗₛᵢ为相应的0—1变量。

不要在可复制正文中显示原始源码式的 `x_{tlsi}`，也不要为每个行内符号重复生成Word输入代码。只有单独居中的公式才执行“双形式”输出。

## 三、长公式、求和、最值与集合

长公式仍将Word输入代码保持为一整行，不得为了视觉整齐在等号、求和号、指数或括号处换行。

显式公式：

\[
z_t^\omega=\left(z_t^{D,\omega},z_t^{P,\omega},z_t^{C,\omega}\right),\qquad z_t^\omega\sim N\left(0,R\right).
\]

Word公式框输入代码：

```latex
z_t^\omega=\left(z_t^{D,\omega},z_t^{P,\omega},z_t^{C,\omega}\right),\qquad z_t^\omega\sim N\left(0,R\right)
```

显式公式：

\[
Q_{ti}=\sum_{l\in L}\sum_{s\in S}Y_{lsi}x_{tlsi}.
\]

Word公式框输入代码：

```latex
Q_{ti}=\sum_{l\in L}\sum_{s\in S}Y_{lsi}x_{tlsi}
```

显式公式：

\[
U_{ti}=\min\left\{Q_{ti},D_{ti}\right\}.
\]

Word公式框输入代码：

```latex
U_{ti}=\min\left\{Q_{ti},D_{ti}\right\}
```

显式公式：

\[
\omega^*=\underset{\omega\notin S}{\arg\max}\ \underset{\nu\in S}{\min}\left\|\mathbf{z}^{\omega}-\mathbf{z}^{\nu}\right\|_2.
\]

Word公式框输入代码：

```latex
\omega^*=\underset{\omega\notin S}{\arg\max}\ \underset{\nu\in S}{\min}\left\|\mathbf{z}^{\omega}-\mathbf{z}^{\nu}\right\|_2
```

只使用已经确认能被当前Word公式模式识别的标准命令。不得使用不存在或兼容性差的命令，如 `\operatornamearg max`；不得把命令拆开或插入不可见字符。若生成Word成稿，应在实际公式框中完成转换检查。

## 四、命令兼容性与实测

Word公式转换以当前Word版本和实际公式框测试为准，不能把某个命令在其他LaTeX环境可用推定为Word一定可用。`^`、`_`、`\frac`、`\sum`、`\min`、`\max`、`\in`、`\sim`、`\left`和`\right`属于本项目已采用的常用表达；不得笼统禁用`\left`、`\right`。

`\underset`、`\mathbf`、`\mathbb`、`\mathcal`、范数命令和复杂嵌套最值在使用前应粘贴到实际Word公式框检查。若出现原样源码、缺括号或布局错误，优先改写为更简单的等价表达，或把冗长条件移到正文；不要仅因截图中偶然可见就把未经实测的复杂命令列为通用白名单。每个独立公式仍只给一整行输入代码。

## 五、分段条件

Word对复杂 `cases` 环境及公式内长段中文的兼容性不稳定。优先在正文说明条件，公式只保留数学关系。例如：

> 当组合(l,s,i)满足适种条件时，aₗₛᵢ取1；否则取0。该变量可以表示为：

\[
a_{lsi}=\mathbb{I}\left\{(l,s,i)\in\mathcal{F}\right\}.
\]

Word公式框输入代码：

```latex
a_{lsi}=\mathbb{I}\left\{(l,s,i)\in\mathcal{F}\right\}
```

不得在公式输入代码中嵌入类似 `\text{作物i允许在地块l的第s季种植}` 的长段中文。只有在表达无法等价简化且已经实测Word可正确转换时，才使用复杂分段环境。

## 六、表格中的符号

表格必须输出为真实表格，不得改写成普通段落、空格对齐文本或代码块。符号列应显示为正常数学符号，不得直接暴露 `x_{tlsi}`、`\omega` 等原始代码。

| 符号 | 含义 | 单位 |
|---|---|---|
| \(x_{tlsi}\) | 第t年地块l第s季种植作物i的面积 | 亩 |
| \(y_{tlsi}\) | 是否安排相应种植组合的0—1变量 | — |
| \(\omega\) | 随机场景编号 | — |
| \(D_{ti}^{\omega}\) | 场景ω下作物i的预期销售量 | 千克 |

符号说明本身不计入正式表格编号时，后续第一张正文表仍从“表1”开始。

## 七、Word使用步骤

1. 在Word中按`Alt`+`=`插入公式框；
2. 将公式输入模式设置为LaTeX；
3. 复制“Word公式框输入代码”下代码块中的完整一行；
4. 粘贴进公式框；
5. 按空格，或选择“转换—专业型”。

## 八、交付前检查

逐式确认：显式公式与单行代码数学含义完全一致；代码只有一行；括号、上下标、集合、范数和运算符完整；正文已解释公式用途和关键符号；Word实测没有命令原样显示、乱码、缺括号或异常换行。

禁止只给代码而不给显式公式，禁止在普通正文中堆放LaTeX源码，禁止把代码拆成多行，禁止在代码外保留公式定界符，禁止使用未经确认的命令，禁止把真实表格改为文字，禁止交付不能直接粘贴进Word公式框的复杂环境。
