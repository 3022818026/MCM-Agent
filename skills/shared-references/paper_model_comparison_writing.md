# 论文中的模型比较写法

## 多模型情形

推荐结构：

1. 建模依据与候选模型设计；
2. 统一数据和评价方案；
3. 比较结果；
4. 最终模型确定；
5. 最终模型建立与求解；
6. 结果、检验和稳健性。

候选模型只说明选择理由、定位、优势和不足。最终模型才完整展开公式、参数、算法、结果和检验。

选择段必须写明指标差异、稳定性、解释性、实际适配以及舍弃其他模型的原因。不得只写“综合评分最高，因此选择”。

## 单模型情形

说明为什么比较无意义或不可靠，再完整给出模型假设、表达、参数、求解、检验、灵敏度和局限。

## 结果措辞

- 区分训练、验证和测试表现。
- 区分观测最好、模型候选、稳健范围和可执行推荐。
- 指标优势限定在相同数据、划分和任务语境内。
- 验证改变结论时如实保留变化，不回退到更漂亮但脆弱的结论。
