# 模型选择与评价参考

## 候选定位

- 基准：透明、可解释、能提供最低性能或可行方案。
- 主模型：解决当前数据结构、非线性、约束或机理困难。
- 专项模型：处理异常、分组、时变、不确定性或特殊代价。

## 评价矩阵

| 维度 | 检查内容 |
| --- | --- |
| 数值表现 | 与任务匹配的误差、分类、目标值或可行性指标 |
| 泛化 | 独立验证、分组验证、滚动回测或交叉验证波动 |
| 稳定性 | 样本、参数、窗口、权重和随机种子扰动 |
| 解释性 | 变量、约束和决策变化能否说明 |
| 可计算性 | 时间、内存、收敛、最优性差距和规模扩展 |
| 适配性 | 是否回答题目、满足约束并符合实际机理 |

## 任务专项

- 预测：报告基准误差、残差、失效区间；必要时给区间。
- 优化：逐项核查约束、基准改进、上下界或小规模精确校准。
- 评价：扰动权重、标准化和指标集，报告排名稳定性。
- 机理：检查量纲、守恒、极限、参数来源和观测对照。
- 启发式：多次运行，报告参数、种子、均值方差和最优性差距。

## 解释边界

相关性、特征重要性和偏依赖只支持关联或预测贡献。训练拟合不等于样本外泛化；把解代回约束只证明可行，不证明全局最优。
