# 常见错误与纠正规则

| 错误 | 纠正 |
| --- | --- |
| 未读附件就猜字段 | 标记附件缺失并停止字段级判断 |
| 默认复杂模型更好 | 与透明基准在同一划分下比较 |
| 所有问题都堆多模型 | 先判断比较是否有意义 |
| 测试集参与调参 | 仅在训练/验证侧选择参数 |
| 时序随机划分 | 按时间或滚动窗口验证 |
| 同对象样本跨集合 | 按真实泛化单位分组 |
| 训练拟合当泛化 | 报告样本外或独立实例证据 |
| 可行当全局最优 | 增加界、精确校准或最优性差距 |
| 数值合理就接受模型 | 同时审查机理、必要条件和参数变化规律 |
| 显著性代替关系形式 | 检查非线性、分层结构和残差 |
| 无益清洗或平衡 | 只保留服务题目目标的处理，并保留真实测量误差 |
| 聚类代替可解释分组 | 检查连续区间、组间差异、样本量和风险含义 |
| 黑箱模型自动优先 | 根据样本、机理、误差和解释要求决定 |
| 相关或重要性写成因果 | 改写为关联或预测贡献 |
| 综合评分最高即最佳 | 检查权重敏感性、稳定性和实际适配 |
| 预测点当实验真值 | 区分观测、预测、稳健区间和推荐 |
| 图更好看而删改数据 | 只优化展示并保留异常 |
| 摘要机械重复“对于” | 总括段加自然衔接的分问段 |
| 公式堆砌 | 公式前交代目的，后解释变量和含义 |
| 论文数字手工复制 | 使用结果ID和单一结果源 |
| 用独立检验情景选择参数 | 改称验证情景，另留最终测试情景 |
| 模型口径更新但旧公式残留 | 执行全链传播检查 |
| 附录使用旧版或绘图脚本 | 锁定唯一最终求解入口 |
| 参考文献为空或正文无引用 | 视为提交阻断项并双向核验 |
| 正文残留占位或协作文字 | 每次续写前与提交前检索 |
| 只检查独立PNG | 在最终PDF实际尺寸下复查 |
| 文档属性或路径泄露身份 | 清理DOCX/PDF元数据和身份路径 |
| 历史模型或评阅数值套新题 | 只迁移原则，重新判断当前题目 |
| 保证规避AIGC检测 | 改为提高表达质量并按规则如实披露 |

## 模型传播、配对比较与图形选择补充

| 错误 | 纠正 |
| --- | --- |
| 模型增加来源组后符号表或目标函数仍用旧粒度 | 重新生成符号表并执行公式—代码—结果—图表全链传播审计 |
| 最小面积、阈值或惩罚权重只给单点结果 | 建立参数台账并做范围/倍率敏感性；次级偏好优先词典序优化 |
| 同一批情景方案只比较各自均值 | 保存逐情景差值、胜率和尾部差异；区间须满足`evaluator_review_principles.md`的适用条件，固定情景可报告范围 |
| 同一收益在不同章节末位不一致 | 从未舍入结果源统一格式化，派生量先计算后舍入 |
| 两条曲线重合后只换颜色或线型 | 改用差值分布、配对散点、斜率图或明确标注的局部放大 |
| 图像代码运行成功即认为完成 | 按论文实际尺寸渲染，自审失败时换图或重排并重新生成 |
