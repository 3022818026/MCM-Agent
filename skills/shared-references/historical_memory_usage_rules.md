# 历史记忆使用规则

## 通用化判断

可复用：题目拆解、数据审查、泄漏防控、异常判断、模型选择、验证、图表、写作、代码和文件管理方法。

必须隔离：字段名、样本量、日期范围、固定模型、参数、节点、阈值、指标数值、图号、最终结论和特定数据划分。

## 使用步骤

1. 读取当前题目和附件，再读取相关记忆。
2. 标记每条记忆为“通用原则”“案例事实”或“用户偏好”。
3. 只把通用原则用于新题；案例事实仅可作为方法示例。
4. 用当前数据重新选择模型、参数、阈值和验证方式。
5. 在输出中注明关键规则的来源，无法核验的内容进入人工确认。

## 禁止迁移

- 不默认使用 XGBoost、Huber、随机森林、AHP、熵权或任何历史模型。
- 不默认固定交叉验证折数、训练测试比例、阶段数或阈值。
- 不把 CUMCM2021B、边坡案例或优秀论文的数值写入新题结果。
- 不把历史成功结果当作当前代码已运行的证据。

## 版本处理

优先采用最新明确修正；旧版本保留为历史依据。存在模型、指标或数字冲突时，先核对结果源和生成程序，不做多数表决。
