# 论文完整性统一门禁

本文件是写作与审核阶段的统一完整性规则源，其他 Skills 引用而不重复维护。

## 路径绑定与增量检查

开始撰写或续写前确认论文绝对路径、最终求解入口、结果注册表、图表清单、支撑材料和当届规则；路径未知时先询问。用户说“下一部分”时重新读取论文文件，上一部分未保存则先确认最新版。

每次续写前检查：

1. 章节顺序、编号和信息归属是否连续，是否重复已有模型、结果或小结；
2. 摘要、正文、表格、图注与结果注册表的同一数字、单位和精度是否一致；
3. 新公式符号是否定义，停用符号和旧模型口径是否残留；
4. 图、表、公式是否已交叉引用，编号和题注是否连续；
5. 正文引用与参考文献是否双向对应；
6. 代码、结果注册表、图表、附录和结论是否来自同一锁定运行；
7. 是否残留“此处插入、下一部分、LaTeX代码、TODO”等协作或编辑文字；
8. 当前修改是否导致结论越界、标题过细或页数预算失控。

确定错误立即回退责任 Skill；语义无法自动判断的项目标记人工复核，不直接判错。

## 模型与验证专项门禁

- 每问直接回答题目要求，给出具体数值、方案或判断，并说明完整结果所在文件/工作表。
- 题目约束、求解设置和数据处理未混入模型假设；问题分析未提前展开公式和算法。
- 递进问题采用增量写法，前问公式不整套重抄；关键结构性结论具有推导、边界、反例、独立算法或文献证据。
- 模型建立与求解分开；搜索区间、步长、停止条件、求解状态和最优性措辞准确。
- 每问至少一项针对核心风险的主验证；验证对象、方法、指标、结果和结论边界完整。可行性不等于稳健性，收敛不等于泛化。
- 人工阈值、最小规模、惩罚、相关系数、弹性和支持集有依据与敏感性；同一情景方案比较有配对差值和置信区间。
- 关键措辞台账中的每项后果性条件均能追溯到变量、方程、约束、目标、情景、验证或明确阻断项；模型说明、实际代码和论文表述具有逐项映射，不存在论文有而代码无或代码改口径但符号与正文未传播的情况。

## 数字、公式、图表与支撑材料

- 符号表覆盖全部现用公式符号且无停用项；目标函数、产量/预测和收入/损失定义的索引粒度一致。
- 同一结果ID由未舍入原值统一格式化，差额、比例、增长率和百分比重新计算，基数、单位、年份、样本数和变量数一致。
- 表格给精确值，图形给趋势/差异/分布，文字给解释，三者不完整重复；重要图按论文实际尺寸自审，重合曲线换用差值图等合适表达且不夸大。
- 附录或支撑材料含文件清单；最终入口、结果文件、图表、完整代码和工作表名称可相互追踪。

## 结构、表达与版式

- 标题层级原则上不超过三级；简单内容不拆标题；共用数据处理集中成章。
- 无教材式大段定义、无证据自评、流程套话、重复题意、重复小结和无分析价值图表。
- 题目与关键词具有区分度；摘要各问包含模型、方法、关键结果和结论，且不超过官方页限。
- 参考文献真实、引用格式统一；DOCX/PDF无身份泄露；页数、正文起始页、页眉页码、表格跨页和AI披露符合最新规则。

## 自动审查与释放

运行 `../paper-review/scripts/audit_paper_integrity.py` 初筛数字、符号、占位、引用、身份元数据、页数和编号；目录、可见页码、页眉、跨页断裂和最终版式逐页人工检查。脚本未检出不等于通过。

释放条件：阻断项为零，高风险问题闭环；内部评分达到 `evaluator_review_principles.md` 的返工阈值；最终入口、结果注册表、正文、图表和附录一致；最终 DOCX/PDF 已按实际尺寸复核。

## 证据主张与问题分级门禁

- 审核每个关键结论、外部事实、引用、经验参数和比较性语句是否有可定位来源，且表述强度未超过来源可支持范围。模型记忆、历史案例印象、检索标题和未经核验的摘要不能支撑具体机制、数值或因果解释。
- 引用核验区分“未找到”与“无法检索”。发现书目信息不一致、元数据被扩写为全文结论、或关键来源不可确认时，修正、降级、删除或列为待用户确认；不得把问题藏在论文正文的占位符中。
- 阻断项优先于任何语言、版式或美化事项：题意/数据口径冲突、无运行来源的数字、核心结果与代码不一致、结论被反证、数据泄漏、身份或官方格式失效均须先回退修复。审核报告中每项阻断和高风险问题都需给出直接证据位置、影响范围、责任 Skill 与复核动作。
- 终审前执行一次反向审视：检查是否仅保留支持性结果、是否遗漏失败情景或简单基准、是否将观察写成因果、是否将条件结论写成普遍结论。发现反证后更新所有受影响的摘要、正文、图表和附录。
