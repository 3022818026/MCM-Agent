# 通用代码、求解记录与支撑材料要求

## 实现原则

- 依据已批准的模型和验证计划实现，不为顺利运行擅自改变数据、目标、约束或评价口径。
- 用户要求完整代码时提供唯一完整可运行入口，不只给片段；原始数据只读，处理数据、结果、图表和日志分开保存。
- 固定或完整记录随机设置、依赖、参数、数据版本、运行命令、停止条件和失败实验。
- 代码实现与论文中的数据处理、变量、目标、约束、划分、随机流、算法、指标、单位和图表输入逐项一致。

## 锁定数据版本与单一来源

- 最终入口先读取数据清单并断言数据版本、内容哈希、模式、单位、行列数、样本ID集合、划分和允许用途；断言失败即停止，不自动回退原始附件或相似文件。
- 描述性分析读取锁定的清洁基础数据；训练、验证和测试读取由训练侧处理器分别生成的模型就绪数据；图表读取锁定结果或图表源数据。任何脚本不得再次临时删除、插补、缩放、编码、平衡或特征选择；交叉验证按`../data-preparation/SKILL.md`的“交叉验证中的处理器归属”执行已批准的每折训练侧拟合，并分别保存处理器和样本ID，不能在整个外层训练集预拟合后直接评价内层折。
- 每个结果ID同时登记清洁基础数据版本、模型就绪数据版本、处理器版本和划分ID。任一数据文件、样本集合、字段、单位、清洗规则或处理器变化时，立即失效依赖的结果注册项并重算评价、图表、正文和摘要。
- 原始数据只用于审计、质量诊断、处理前后对照和复现检查；不得与处理数据混合计算最终指标。确需修改处理规则时回退`data-preparation`并发布新版本，不在实现、绘图或写作阶段补丁式修数。

## 模型—代码反向核对

- 完整运行前建立映射表：原始字段到代码变量，数学符号到数组/索引，核心方程到函数或表达式，每类约束到生成逻辑与独立断言，算法步骤到循环/求解器配置，中间量到保存文件，论文结果到结果ID。
- 运行后从实际入口反向核对最终模型，而不是只检查代码是否报错。逐项确认代码真正实现了题面对象、索引粒度、目标方向、边界条件、随机流、停止条件和评价口径，并检查未被使用的公式、约束和参数。
- 代码与设计不一致时，必须根据题目和证据修正代码或更新最终模型说明；随后使结果注册表、评价、图表、正文和附录全部转为待复核。不得让论文继续描述未执行的模型，也不得为迁就现有代码静默改变题意。
- 脚本入口、子进程和测试命令使用当前环境已解析的解释器路径或跨平台调用方式，不硬编码只在某一操作系统存在的命令名；中文输入输出显式指定编码并用包含中文、空格和长路径的最小案例验证。

## 统一评价器与模型接口实现

- 当多问、多候选或优化算法共享同一效果判据时，将其实现为单一评价模块，输入为状态、决策、参数和精度配置，输出为原子事件/区间、聚合指标、可行性与诊断信息。正文结果、基准、候选算法和回代验证均调用该模块，不复制多份近似逻辑。
- 为评价器设置解析/手算小例、边界、离散精度和重复计量测试。覆盖时长、面积、对象数或概率等存在重叠时，同时保存原子结果和去重后的聚合结果，明确并集、交集、唯一键或条件事件的实现口径。
- 模型串联时保存机器可读接口表，至少含上游结果ID、实体与时间索引、单位、未舍入值、不确定性/情景、适用域、配置版本和下游消费者。统计量、拟合参数或预测概率进入风险与优化前执行范围、单位、缺失、单调方向和版本断言。
- 先实现透明或低成本路径生成初值、可行域或诊断，再运行精细拟合/优化；粗路径与精细路径分别登记，粗结果不得冒充最终结果，精细模型失败时不得静默回退并沿用旧结论。

## 非光滑事件与联合精度

- 当切换、接触、冲击、阈值穿越或分段系数影响目标量或约束时，显式实现模式、事件函数、触发方向及题意要求的连续/跳变关系。不能让跨事件的光滑插值、求导或峰值拟合抹去真实不连续；模式内插值或经证明适用的方法仍可使用。
- 保存事件位置/时刻、前后模式、必要的单侧状态或导数、定位容差及触发记录；对可能漏掉的短时事件、切触或多次穿越，采用与问题结构匹配的检测和复核，不能仅凭采样点未变号断言无事件。
- 对最终方案提供独立调整实际离散维度及联合细化的入口，保存精度配置、固定决策、目标量、事件和约束裕度的未舍入结果；判定按[evaluator_review_principles.md](evaluator_review_principles.md)的专项复核执行。约束数值余量与题意要求的物理安全裕度分别记录。

## 专项验证的实现交接

- 验证卡触发目标量诊断时，输出已定义区域/事件的选择规则、观测与模型对应关系、整体及局部误差、目标量和参照来源；不能在写作或制图阶段临时改窗口或重算另一种口径。
- 模型卡触发嵌套退回检查时，保留可切换的新增机制或明确的退回配置，记录基础与扩展版本、映射、相同输入、比较对象、容差和失败结果。关闭开关后仍残留新增项属于实现问题，不把两次使用同一错误函数的自洽当作独立验证。
- 这些证据登记在已有运行清单、结果注册表和评价报告中，字段随实际题型选择；不为未触发的检查创建空报告，不改变MATLAB求解与Python绘图分工。

## MATLAB分析与Python绘图协议

- 当前用户的新项目默认使用MATLAB实现数据处理、数学建模、数值求解和验证，使用Python实现最终论文图表。当前偏好环境为MATLAB R2023b和Python绘图库；具体可执行文件、版本、Toolbox、Python解释器和关键包必须在每个项目的环境预检中解析并登记。不得把本机绝对路径写入通用规则、可交付代码或论文。除非用户最新要求改变，或MATLAB无法完成必要任务且用户明确同意，不切换建模主流程到Python、R或其他语言。
- 指定唯一最终入口，通常为`main.m`，并按读取与审计、参数构造、模型/求解、评价、导出拆分本地函数或独立函数文件。文件与目录使用`fullfile`和项目相对路径，不把个人绝对路径写入可交付代码。
- 随机过程用`rng`固定并登记生成器与种子；记录MATLAB版本、所需Toolbox、求解器选项和许可证依赖。依赖缺失时报告并设计MATLAB内可复现替代，不静默改变算法。
- 表格型数据优先用`readtable`、`writetable`、`table`或`timetable`保持字段、单位和时间索引；数值结果同时保存未舍入值、显示值、单位和结果ID，必要时保存`.mat`中间状态。
- 优化与拟合代码保存求解器、`exitflag`、`output`、可行性、停止条件、最优性间隙或残差；随机、搜索和仿真代码保存逐样本/逐情景结果与收敛轨迹。MATLAB执行成功不替代约束、量纲、边界和独立复算。
- MATLAB导出锁定的图表源数据；Python绘图脚本只读取这些结果或图表源数据，优先使用figure-generation/scripts/paper-plot-library/paper_plot_library.py生成PNG，禁止在绘图脚本中手工覆盖核心数值。交付前依次执行代码分析、最小样例、完整运行、结果注册核对和无个人路径检查。

## 计算规模、搜索与收敛

- 论文需要复述的核心求解步骤应能对应“输入/依据—实际操作或更新规则—停止/判定条件—输出及消费者”。记录实际执行的算法变体、关键超参数的选择依据和配置，不把调用库函数改写成没有执行过的算法。
- 蒙特卡洛或随机仿真记录采样机制、独立性或依赖结构、重复量、估计量和适用的不确定性计算方法；抽样误差、离散误差与模型误差分别说明。模拟次数根据目标精度与收敛证据确定，不固定最低次数。
- 保留求解器和数值警告。仅对已查明无关的特定警告局部过滤并说明原因，不全局关闭警告后把运行结束当作成功。


- 记录决策变量数、约束数、样本/情景数和主要时间/空间复杂度；组合空间快速增长时说明精确求解是否可行。
- 搜索、迭代和模拟保存初始区间、步长/精度、区间缩小规则、迭代或样本量、停止条件、最终精度、运行状态和时间。
- 适合时输出收敛轨迹、不同精度结果、多随机流重复或小规模精确对照；程序成功不能代替模型正确性、收敛性或最优性证据。

## 结果注册与传播

结果注册表至少包含问题编号、结果ID、未舍入原值、显示精度、单位、数据/配置/运行版本、模型、参数、划分、指标、代码入口、结果文件、图表、状态和生成时间。

只有成功并通过合理性检查的结果才能进入论文。重新运行或模型口径变化时解锁受影响结果，全文检索旧值、旧符号和旧图，并重新生成下游产物；派生量先用未舍入值计算再格式化。

## 验证数据输出

- 最小示例、边界、单位、维度和约束自动检查。
- 预测保存逐样本预测、真实值和划分；优化保存逐类约束审计、求解状态和最优性证据；随机方案保存逐情景结果而非只有均值。
- 人工阈值、惩罚和权重提供批量敏感性入口；复杂流程在干净目录抽查复现。

## 支撑材料清单

每次最终运行自动或半自动维护支撑材料清单，至少记录：文件名、对应问题、用途、程序入口或工作表、主要输出、完整结果位置、依赖关系和状态。正文、附录和提交包只能引用清单中的锁定文件。

完整长代码、完整矩阵和完整决策结果按竞赛要求放入统一附录或独立支撑文件；绘图脚本不能冒充最终求解入口。

## 禁止

不手工修改核心输出，不使用未成功运行的数值，不复制历史案例结果，不为美观改数据，不让旧代码或旧图继续为新口径提供结果，不把“使用Python”当作算法可行性说明。
