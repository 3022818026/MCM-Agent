# 评阅视角与逐问验证原则

本文件汇总跨题型评阅与验证规则。历史年份、题号、参考范围和个别方法只作为风险线索，最终以当前题面、附件、官方规则和可核验来源为准。

## 建模时同步设计验证

每问在模型确定前建立验证卡：核心风险、主验证、必要辅助验证、需保存的中间结果、评价指标、图表以及每项证据能支持的结论。模型、代码和图表必须为该验证保留数据，不能到写作末期临时补一句“模型合理”。凡预计使用“稳定、减少重叠、均衡、效率、稳健、可实施、可复核、显著改进”等评价性结论，设计阶段即按`evidence_claim_discipline.md`的最低证据矩阵预留逐次、逐情景、原子区间、运行成本、扰动结果和追踪字段。

每问至少有一项针对核心风险的主验证；仅在确有不同风险时增加1—3项辅助验证。每项验证明确对象、方法、指标、结果和结论边界。约束检查只证明可行，收敛只证明数值过程稳定，灵敏度说明参数影响，样本外检验说明泛化或情景过拟合，残差说明误差结构。

## 验证职责分离与模型晋级

- 在验证卡中为每份数据、情景和计算路径指定唯一主要职责：建模/校准、选参/选模、独立验证或压力/失效测试。用于校准、窗口选择、权重确定或阈值选择的对象不得再称为独立验证；联合拟合可提高估计稳定性，但不能替代保留条件、替代路径或合成已知真值的独立核验。
- 同一结论优先由职责不同的证据支持：结构或粗估给出方向和初值，精细模型给出最终量，回代/重构观测检查机理，跨条件数据检查可迁移性，扰动或合成数据检查恢复能力。不同图表若来自同一残差或同一代码路径，只算同一证据族，不以数量冒充独立性。
- 复杂模型只有在基准残差仍有系统结构、跨条件不一致、边界失真或题面机制缺失，并且新增机制针对该失配时才晋级。晋级后复查原失配是否减少、关键参数是否可识别、结论是否更稳定以及计算成本是否值得；否则保留简化模型。

## 目标量与目标区域专项诊断

- 最终答案依赖局部区间、极值、阈值事件、尾部风险或派生目标量时，在验证卡中预先定义目标量、区域/事件选择规则、参照证据、误差口径及其对决策的影响。区域可按题意由数据确定，但不能看过误差后挑选有利区间；用于选区、校准或调参的数据不再称为独立验证。
- 有观测对照时，同时检查整体拟合、目标相关区域的残差结构，以及按同一定义计算的目标量误差；必要时核对事件时刻和区间边界。保存模型值、参照值、单位、来源、不确定性和判定，不能只凭全局RMSE或R²放行关键答案。
- 没有可用实测参照时，按风险使用解析特例、独立实现或数值细化，明确这些只支持对应的计算一致性或误差控制；目标量的实测准确性记为未核验，不虚构“实测值”。
- 容许误差来自题目精度、观测噪声、数值误差及方案排序/约束判断的敏感性，不设跨题型统一百分比。参照接近零时报告绝对误差或有依据的尺度化误差，避免相对误差失真；实际偏差足以翻转关键判断时不得仅因整体拟合良好而放行。
- 发现系统失配后先提出可证伪的机制解释，再以未被用于该修改的证据复核；比较中保留整体与目标量指标的得失。不要求所有指标同向改善，也不把单项取舍直接等同过拟合；是否保留改动取决于题目目标、独立证据与代价。

## 事件模型与扩展模型的专项复核

- 对包含模式切换、接触、阈值穿越或分段系数且会影响答案的模型，复核事件遗漏、事件两侧关系和实际采用的离散方案；实现及记录要求见[非光滑事件与联合精度](common_code_requirements.md#非光滑事件与联合精度)。
- 对最终候选固定同一决策和参数，分别检查实际存在的时间、空间、事件定位或其他离散误差，再联合细化；同时比较题目目标量、关键事件和全部受影响约束。无需空间离散的模型不补造网格检查。若另行重优化，区分固定方案重算误差与重新搜索带来的变化。
- 精化导致可行性翻转、排序改变或关键答案未稳定时，回退补算或限定结论；不得放宽原约束或调整显示精度掩盖问题。稳定细化只能支持对应数值精度，不能证明物理真实性或全局最优。
- 嵌套扩展按[退回基础模型规则](common_modeling_principles.md#嵌套扩展与退回基础模型)核对推导、实际代码与退回结果；不能仅因接口表写有“继承”就认为一致性已验证。

## 正确性证据阶梯

评价强度按当前模型核心风险选择，优先形成四层证据：透明基准或特殊情形、回答题目的主模型、独立交叉核验、压力/边界/失效测试。四层不是固定模型数量：同一解析推导、精确小规模枚举、替代算法、重构观测量或留出数据都可以承担一层；若某层不适用，必须说明原因和剩余证据边界。

- 透明基准用于检查方向、量级、可行性或改进是否真实，不要求追求最高指标。
- 主模型必须完整实现关键题面措辞，不能以结果接近参考范围替代机制正确。
- 交叉核验尽量使用不同证据来源或不同计算路径；同一代码改参数重复运行不自动构成独立核验。
- 压力测试围绕最可能推翻结论的参数、噪声、边界、分布漂移、约束或失败样本设计，不机械罗列所有指标。
- 审核时反查关键措辞台账；任何会改变结论的题面条件若未进入模型、情景、验证或明确阻断项，按机理遗漏处理。

## 自动检查的证据边界

- 静态脚本擅长检查文件、字段、章节、编号、占位符、路径、关键词和可追溯关系是否存在，但不能仅凭这些形式证据判断公式正确、论证成立、代码与模型语义一致或结论真实。
- 自动检查通过只能表示已通过该脚本覆盖的项目。评价仍须读取原始题面、数据、实际代码和逐对象结果，抽查关键公式与约束，独立复算代表性数值，并按正确性证据阶梯执行语义核验。
- 验证器同时报告覆盖范围与未覆盖风险；不能用关键词出现、字符数达标、文件存在或退出码为零替代数学正确性和评阅判断。

## 模型机理与关键判断

- 保留决定结果的关键变量、函数关系和必要条件，不把随时间、波长、空间、群组或状态变化的量无依据地设为常数。
- 数值接近合理范围不能掩盖机理错误；先用附件证明确有该现象或必要条件，再建模。
- 影响模型结构、变量削减、约束简化、搜索范围和最终结论的判断，需要推导、边界、反例、独立算法或文献证据。
- 尽量把估计参数代回模型，重构可观测量并与附件数据比较；保留负面验证和失效区间。

## 方法与数据适配

- 检查线性、非线性、分层、聚类、分类、优化和机器学习是否匹配数据结构；显著性不能替代关系形式和残差检查。
- 连续变量分组应保持区间连续、组间差异有意义、样本量不过度失衡；聚类不自动等于可解释分组。
- 测量误差、机理约束和小样本存在时，黑箱方法不能自动优先；清洗、插补、平衡和分组必须服务题目目标。
- 区分附件、允许公开资料和禁止外部数据，不用额外数据绕过限制。

## 题型匹配验证

| 题型 | 主验证重点 |
| --- | --- |
| 优化规划 | 逐类约束违反数、求解状态、最优间隙/界、基准方案、参数敏感性；随机优化使用未参与求解的情景 |
| 预测/时间序列 | 合理划分、透明基准、MAE/RMSE等任务指标、预测—真实对照、残差与失效区间；时序不随机打乱 |
| 分类 | 混淆矩阵、Precision、Recall、F1、ROC-AUC/PR-AUC、类别不平衡、阈值和误判代价 |
| 聚类/分组 | 簇内与簇间差异、聚类数、稳定性、样本量、连续边界和现实解释 |
| 几何/运动/路径 | 几何约束、距离与角度误差、边界/碰撞、步长或搜索精度、关键位置独立复算 |
| 微分方程/仿真 | 初边值、量纲与守恒、步长收敛、参数敏感性、特殊情形解析对照和物理合理性 |
| 评价决策 | 指标和标准化依据、权重敏感性、排名稳定性、基准与实际解释 |
| 启发式/随机算法 | 多随机流重复、分布与置信区间、停止条件、小规模精确对照或可得上下界 |
| 反演/参数估计 | 结构或频域粗估、参数回代重构观测、残差结构、跨实验条件一致性、参数可识别性与合成真值恢复 |
| 统计到决策链 | 上游概率/参数校准、接口单位与索引、风险函数方向、决策回代、误差传播及推荐反转阈值 |

指标按任务选择，不机械堆满表中项目；准确率、R²、约束违反数或单次最优值均不能单独证明模型优越。

## 算法与可靠性

- 检查自动执行能力、必要人工干预、噪声鲁棒性、重复一致性和可复现性。
- 优化模型报告可行性、目标值、求解状态、最优间隙、时间上限和停止标准；不能把可行写成全局最优。
- 搜索与仿真检查区间、步长、迭代/样本量和收敛；随机结果报告波动或置信区间。
- 两方案使用同一批样本或情景时保留配对差值；置信区间按下节适用条件决定，差异小于有效误差范围时不宣称稳定改进。

## 重采样与置信区间适用条件

- 先登记估计目标、随机来源、观测单位、配对关系、独立性/依赖结构、重采样单位和可支持总体；配对只保留对应关系，不自动保证各对之间独立。区分抽样不确定性、随机算法波动、蒙特卡洛误差与固定情景敏感性，不互相替代。
- 只有观测单位独立且具有相应抽样解释时，才考虑普通配对Bootstrap。时间序列按依赖结构选择有依据的区块或其他方法；同一对象重复测量、群组或空间依赖按独立组或适配结构重采样，并说明组数、块长及敏感性。交叉验证折次共享训练样本时，不把折均值当作独立样本机械计算置信区间。
- 固定政策方案、穷举情景或人为压力场景若没有随机抽样含义，报告逐情景差值、范围、胜率或最坏情况；置信区间登记不适用及原因。条件未知时先补充依据或明确未核验，不能凭“分布未知”自动选择Bootstrap。
- 实际计算区间时记录统计量、方法、置信水平、重采样次数、随机种子、失败/退化样本与稳定性检查；次数按精度和资源决定。区间计算失败或包含非有限值时不能写成有效区间。绘图只消费评价阶段已核验的区间；模板内统计便捷函数不能替代该审核。

## 模型评价与推广

评价改进归因时，按[evidence_claim_discipline.md](evidence_claim_discipline.md)的“贡献类型与证据边界”核对实际改动、比较条件和代价；未实现的改进与没有新颖性证据的贡献分别限制措辞。

优点必须能回指正文证据；不足聚焦真实数据、假设、参数、计算或泛化边界；推广说明目标场景、需替换变量、需扩展约束、适用条件和新增数据，禁止空泛口号。

## 内部100分审查尺

可选内部诊断评分：模型正确性与适配25、问题逻辑与结构15、正文信息密度15、标题层级10、验证完整性15、数值一致性10、图表/流程图有效性5、语言与格式5。评分只用于定位问题，不作为自动发布或返工门槛；采用评分时记录扣分对应的具体缺陷、证据和适用项，不适用项不按零分处理。

必须回退修订的依据是未关闭的阻断项或高风险缺陷，包括题目要求遗漏、关键机理错误、必要验证缺失、数值来源不一致和结论越界；逐项登记证据、责任阶段与验收条件。分数高不能抵消缺陷，主观分数低也不能单独触发反复返工。数值合理但机制错误仍属高风险；表达漂亮但结果来源不真实属于阻断项。

## 结论校准与反向审视

- 每项评价结论先写出其证据来源、可支持的范围和不支持的推断；指标、图表和文字均不得越过该边界。比较性结论同时报告比较单位、数据划分、配对关系和不确定性来源。
- 路线锁定、主结论和最终审核前，反向检查是否遗漏反例、失败样本、替代解释、简单基准或不利情景。反证推翻结论时改写或放弃；仅削弱时补充条件边界；不同但兼容时并列呈现。
- 自动脚本、同一代码的重复运行和自洽叙述不能替代独立核验。独立性来自不同数据、不同实现路径、手算/小规模对照、可观测量重构或隔离的审查视角。
- 在当前证据无法区分候选模型时，结论应为“尚无充分证据表明存在稳定改进”，并按透明性、稳健性、资源与题目适配度选择，而不是用综合分或措辞强行排出优劣。
