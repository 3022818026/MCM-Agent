# 外部学术终审规范的可迁移审查透镜

## 定位与权威边界

本文件将用户提供的 Supervisor-Skills 中 `paper-polish`、`paper-writer`、`pre-submission-reviewer` 与 `figure-designer` 的**可迁移终审原则**转化为数学建模论文的复核透镜。它用于补全终审视角，不是题目证据、正文模板、竞赛硬规则或外部事实来源。

语言与语义仍以 `academic_style_revision.md` 为最高权威；事实、引用、数字和结论边界仍以 `evidence_claim_discipline.md` 为最高权威；结构、图表、交付格式和官方要求分别服从其在 `rule_authority_index.md` 中列出的本地权威来源及用户最新要求。本文件出现冲突时，以上来源优先。

当用户指定可访问的 Supervisor-Skills 根目录时，`paper-review` 必须复读其中与当前风险相关的原始规范，核对本透镜是否覆盖；无法访问时，依据本文件完成审查，并如实说明未进行外部源复核。不得把外部案例、术语、参考文献、数字、模板句或软件要求写入当前论文。

## 终审前置：提交画像与覆盖声明

- 审核开始前绑定竞赛与题目、论文阶段、正文语言、官方模板、提交文件及源文件、代码入口、结果注册表、图表和附录，说明哪些材料已完整读取、哪些只能自动初筛、哪些需要人工判断、哪些不可访问。
- 先判断当前题型与核心风险。优化、预测、分类、仿真、评价和机理问题使用不同的正确性证据，不用统一的期刊实验范式审核所有论文。
- 长文可以分块读取，但必须覆盖全部页、章节、图表、公式、参考文献和附录，并记录分块范围；抽样只能用于辅助复核，不能据此声称完成全文审查。
- 当届规则、引用真实性或外部事实具有时效性时重新核验；无法检索或无法访问原文时标明能力边界，不以“未找到”推断不存在。
## 四个必检维度

### 1. 语义忠实与主张校准

- 以原文、结果注册表、代码和题面为语义锁，检查润色、压缩或重排后是否改变了问题对象、条件、比较对象、因果方向、范围、时态、不确定性或限制条件。
- 每个效果、优劣、适用性、因果和推广性主张都应由当前提交包中的相应证据支撑；强断言必须与证据强度相称，不能用“首次”“最优”“显著优于”“解决”等措辞替代验证。
- 区分观测结果、解释、推测和计划；不得补造数据、机制、案例、实施细节、数值、文献或引用，也不得将仅有元数据的文献当作全文证据。
- 相关工作、基准方法和失败案例应被准确、平衡地描述；批评必须有可定位的比较依据，不能通过弱化对照来抬高本文方法。

### 2. 论证链、自包含性与一致性

- 检查句子、段落和章节是否各自承担明确作用并自然衔接：主张应紧邻其理由、公式、结果或引用，不能只靠结论性断言推进叙述。
- 首次出现且影响理解的术语、符号、指标、算法步骤和数据处理应在可理解的范围内定义；图表标题、坐标、单位、图例和说明应使读者脱离正文也能正确理解图表所示内容。
- 反查“题目小问—数学转化—模型/代码—结果ID—图表—结论”的链路。不同章节、不同小问和附录使用的术语、符号、样本范围、版本与数字必须一致。
- 将外部研究论文常见的“贡献—模块—消融—基准”链，转译为当前竞赛论文实际需要的模型—验证—结论链；没有对应实验或证明的主张应降级、删除或路由修复。

### 3. 分节职责与正文质量

- 摘要应可独立说明问题、方法、已核验的主要结果及必要边界，不用空泛褒义词或未核验数字填充；正文各节不得以换序方式重复同一论证。
- 建模部分说明问题转化、假设、符号和方法；结果部分先清楚报告观察到的数值或规律，再在有依据时解释；模型评价说明证据与限制；结论回答题目而不引入新模型、新结果或新论据。
- 审查段落主题句、信息密度、过渡与术语稳定性，识别空泛衔接语、口号式总结、程序化AI语气和无效重复；判断标准是是否损害准确性、可读性或论证，而不是机械禁用某个词或固定句式。
- 语言层面的语法、标点、排版和输出语言，按当前论文语言、官方规则及用户交付契约审查；不把外部规范中的英文专属语法、固定段落数或固定篇章节结构作为数学建模硬性要求。

### 4. 审查记录、引用与图表呈现

- 审核应覆盖交付范围内的完整正文及相关产物，不能用抽样或同一上下文自检代替关键结论的独立复核。每个阻断项或高风险项都要定位到具体文件、页码/章节/表图/结果ID或代码位置，说明影响、修复动作和复核证据。
- 引文应真实、相关、可追溯并与文中主张匹配；文内引用与参考文献双向对应。检索或原文不可得时，标注可核验范围，不能由未检索到推断文献不存在。
- 图表应在正文中有明确任务和引用，先解释其用途再呈现；标题或图注应说明图表对象、指标/单位、必要条件和可支持的发现。检查缩放后的可读性、颜色之外的区分方式、坐标尺度、误差表达与黑白打印效果。
- 视觉元素仅在编码数据或降低理解成本时使用。三维、渐变、阴影、纹理和强调色均按是否扭曲数据、遮挡比较或违反当前用户偏好判断；3D图仅在数据确含第三维或层级且二维表达会丢失关键信息时使用，单一构成、类别比较和精确读数优先二维表达。

## 主张—模块—证据反向映射

- 为每项核心结论建立“题目要求—数学转化—模型机制—代码/求解—结果ID—验证—图表/正文”反向映射。任何孤立主张、孤立模型模块、孤立结果或没有验证支撑的结论均需登记。
- 核查摘要、问题分析、模型建立、结果分析和结论中的同一核心主张是否含义一致；名称变化、条件消失、比较口径改变或结论强度升级均视为传播风险。
- 论文若声称某个新增模块、惩罚项、约束或算法步骤带来改进，应使用消融、替代路径、敏感性、反事实或其他适配证据隔离其贡献。没有归因性主张时不机械要求消融；无法隔离时将结论降为整体方案表现。
- 引用方法、外部机制或经验参数承担关键论证时，正文须给读者理解当前模型所需的最小解释，不能把承重逻辑全部外包给文献。

## 分节角色复核

| 位置 | 终审问题 |
| --- | --- |
| 摘要 | 是否独立回答研究对象、最终方法、关键结果与边界，且数字全部可追溯 |
| 问题背景与重述 | 是否忠实压缩题意、区分背景与任务，并避免提前给模型和结果 |
| 逐问问题分析 | 是否逐问说明数学转化、困难、模型理由、承接关系与交付物 |
| 假设与符号 | 假设是否必要且有边界；所有现用符号是否唯一、完整、无旧口径残留 |
| 模型建立与求解 | 机制、目标、约束与题面是否对应；算法、参数、停止条件和求解状态是否可复现 |
| 结果与验证 | 是否先报告真实观察，再给解释；验证是否针对核心风险并能支持当前措辞 |
| 评价与结论 | 是否具体说明优势、限制和适用范围；是否直接回答题目且不引入新结果 |
| 引用与附录 | 引用是否双向对应；完整代码、结果和支撑清单是否能复现正文核心结论 |

## 发现质量、严重度与提交结论

- 每个阻断项和高风险项必须给出精确证据锚点，可使用文件路径、页码、章节、段落首句、公式号、图表号、结果ID或代码位置；引用原文时只能逐字引用真实存在的短片段，不得生成近似引文。
- 每项发现写清“问题—影响—严重度—修复动作—责任Skill—复核证据”。“整体重写”“补充说明”“建议优化”等不可验证措辞不能单独作为修复方案。
- 严重度按对题意、数学、数据、结果、可复现性、合规或评审理解的实际影响确定；措辞偏好、固定段落长度、单个词语或个人审美不得被夸大为阻断项。
- 自动检查、全文机械扫描、人工语义审查和需用户确认的事项分别标明覆盖范围。全文扫描应覆盖占位符、旧变量、断号、未引用图表公式、无来源强断言、身份信息和其他当前项目已登记模式；大文件分块时记录分块策略。
- 审核摘要先给最优先的三项修复，排序依据为否决风险、传播范围和前置依赖，而不是问题数量。最终结论必须与未关闭问题一致：存在阻断项不得写“可提交”；高风险项未闭环不得写“终审通过”。

## 条件触发的外部检索与语言检查

- 仅当论文作出首创、最新、代表性方法、关键引用或外部事实主张时，才检索最接近工作、奠基文献或权威来源；比较须基于可访问正文或可靠摘要，标题相似和搜索片段不能证明方法相同、遗漏或首创。
- 中文正文不套用英文冠词、时态、which/that、引号或破折号规则。存在英文摘要或英文附录时，只对相应英文内容按目标模板和通行语法进行条件检查，不把固定时态配方当作普遍硬规则。
- 数学建模当前以Word为主要交付时，不迁移LaTeX目录拆分、标签命名、波浪号引用、矢量图唯一化或修订宏；只吸收其背后的编号连续、交叉引用、题注完整和实际版面检查原则。
## 不可直接迁移的外部约束

- 顶会/期刊的固定章节、摘要句数、段落数、图数、数据集数、基准/消融数量和所谓“贡献”叙事配额；
- LaTeX 命令、双栏版式、矢量格式唯一化、英文标点或禁词清单等特定投稿环境要求；
- 外部技能中的案例、研究结论、引用、数值、工具链、软件权限与文件路径；
- 用格式化检查、词频扫描或同一 Agent 的重复自检替代对数学、数据、代码和结果的实质核验。
- 固定三至五天审稿时点、五维输出框架、1—10分评分、固定严重问题数量阈值、英文禁词表和破折号一票否决规则。

## 终审落地要求

`paper-review` 以本透镜进行补充复核后，仍使用 `quality_gate_protocol.md` 的阻断/高风险/改进项分级和问题台账。问题报告应写出可验证的本地证据及修复路径；本文件只说明审查视角，不为任何结论提供证据，也不允许在未闭环的情况下宣称论文已通过终审。
