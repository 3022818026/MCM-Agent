# 数学建模 Agent 十三阶段按需调度工作流

本文件只负责每轮需求路由、范围控制和失败回退。阶段编号、定义、提示词、命名交接物和放行条件唯一引用[MATH_MODELING_AGENT_PROMPT_CHAIN.md](MATH_MODELING_AGENT_PROMPT_CHAIN.md)，不维护其他阶段序列。八个Skills通过常驻规则索引进入本文件，再读取提示链。

## 每轮阶段选择

每次收到提问或新需求，先执行以下判断，并在内部形成`stage_selection`，对用户简要说明本轮将做什么：

- 识别意图：解释/咨询、诊断/审查、局部产出、修改/续作、完整求解或完整交付。检查Agent配置属于维护任务，不启动赛题求解；一般概念咨询可以不选执行阶段，也不强制索要赛题数据。
- 锁定范围：具体题目、小问、章节、图、代码或文件，以及用户是否要求实际运行、生成文件或修改。继承仍有效的上下文、偏好与授权，最新明确要求优先。
- 核对证据：检查已有题面、数据版本、模型卡、代码、结果注册表、评价、图表和正文的可访问性与有效状态；文件存在或旧会话声称完成不等于已核验。
- 选择阶段：从十三阶段中选择直接完成当前需求的最小充分集合，再补上缺失或失效的必要前置阶段。按依赖顺序执行；未选阶段不标记通过，有效前置可复用而不重跑。
- 确定终点：记录所选阶段、理由、输入版本、复用证据、需补齐前置、输出、完成证据与停止点。完整交付规划全部适用阶段；局部完成不自动接着写论文、摘要或生成文件。
- 处理变化：执行期间的新消息按当前任务的补充、缩小、扩大、替换或状态询问处理；状态询问不自动取消任务。新数据或结论变化时重算阶段选择并登记下游失效范围，不沿用过期计划。

## 典型请求与阶段范围

下表是初始路由示例，不是关键词触发器；最终选择取决于实际产物、证据和授权。

| 本轮需求 | 通常选择的阶段 | 必要边界 |
| --- | --- | --- |
| 解释概念、了解Agent工作流 | 无需执行赛题阶段 | 只回答当前问题，不要求无关附件 |
| 只分析题目或某一问 | 1；需论证结构或模型设计时选2—4中的所需部分 | 不自动编码或写完整论文 |
| 检查、清洗数据 | 1中的data-preparation | 锁定处理数据，登记失效下游，不自动训练 |
| 设计模型、推导公式 | 3—4；需要论文结构时补2 | 核验1的相关证据，候选不写成真实结果 |
| 实现、求解或修正程序 | 5；真实结果交付需要6 | 先核验3—4及数据；只给代码时不代运行，标记未运行 |
| 比较模型、验证、敏感性 | 6 | 没有成功运行结果则先核对缺口；需要补算时在授权内回5 |
| 重画指定图 | 8—9 | 核对有效图表数据；仅需调整现有设计时复用8，不扩大到全套图 |
| 筛选论文图表或从结果生成整套图 | 7—9中的所需阶段 | 未验证的结果先处理6，数据错回1，代码错回5 |
| 写或润色正文、继续下一节 | 10；涉及章节关系时加11 | 阶段10涵盖按蓝图编写所需正文；复用2—9中适用证据，纯语言修改不重算、不重绘 |
| 只写摘要 | 12 | 核对稳定正文、结果与验证；缺证据则补必要前置，不虚构数字 |
| 审查完整论文或提交包 | 13 | 先报告问题；仅在获授权修复时回对应阶段，之后复核 |
| 完整解决赛题并交付论文 | 1—13全部适用阶段 | 复用当前有效产物；不适用项登记理由，不跳过核心科学核验 |

## Skill责任与交接

每项具体动作只设一个主Skill：总控由`modeling-scientist`负责；审题细化、蓝图和模型设计由`modeling-design`负责；数据准备由`data-preparation`负责；实现由`model-implementation`负责；独立评价由`model-evaluation`负责；图表由`figure-generation`负责；正文与摘要由`paper-writing`负责；全文独立终审由`paper-review`负责。阶段1和6的专业切换顺序交接，不把一次调用冒充两个独立角色。

只执行当前选中阶段的交付范围。写作期间的增量检查由`paper-writing`承担，不因每写一节就启动完整`paper-review`。必要前置未满足时，可在现有授权内补齐；需要新的用户选择、附件或权限才请求最小必要信息，不对已获授权的动作重复确认。

## 短指令意图补全与应急模式

- 对“分析题目”“继续写”“优化模型”等短指令，按覆盖范围、所处阶段、所需产物和质量标准补全意图。可从当前上下文确定的直接继承；只有缺口会改变模型、数据口径、修改范围或交付格式时才询问。
- 截止时间紧时，先处理题意误读、附件缺失、硬约束、数据泄漏、不可复现、结论越界、数字不一致和官方格式否决项。可缩小候选与装饰性产物，但不能降低数学正确性、结果真实性、核心验证及官方硬规则。

## 阶段释放与即时回退

- 数据问题回1的数据准备；题意、假设与路线回1或3—4；蓝图回2；代码或计算结果回5；验证和结论边界回6；图表回7—9；正文和衔接回10—11；摘要回12；终审在13复核。
- 从最早受影响阶段修复，重算或更新实际受影响产物并重新核验。局部任务范围外的失效产物只登记待复核，不自动修改或发布。
- 交接物可在当前对话或项目现有清单中登记；纯咨询不新建文件。完整项目保存必要代码、数据、日志和结果清单，成品文件按用户要求生成。
- 审核材料不完整时说明覆盖范围；静态脚本通过不能代替数学正确性、独立验证或全文终审。最终发布必须满足适用质量门禁。
