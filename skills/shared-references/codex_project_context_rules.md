# Codex 项目上下文规则

## 证据范围

当前“项目”指 Codex 中持续使用的项目空间、对话和文件，不默认是 Git 仓库。不得假定存在提交、分支、工作树或完整历史对话。

可使用来源按优先级排列：

1. 当前对话中用户最新的明确要求；
2. 当前可见的较新对话要求；
3. 标注为当前或最终版的 Markdown 记忆；
4. 当前题目的最终代码、论文和成功运行结果；
5. 较早经验总结；
6. 无法判断时转入人工审核。

## 访问边界

- 只声称读取了实际打开并检查过的内容。
- 文件名不能代替文件内容。
- 历史对话不可见但有 Markdown 记忆时，明确写“依据该记忆文件”。
- 两者均不可访问时写：`当前Codex项目中未找到可核验的历史依据，需要人工确认。`
- 不扫描缓存、虚拟环境、第三方依赖和无关编译产物。

## 冲突记录

发现冲突时记录：早期要求、后续修正、最终采用、采用依据。不得因旧文件更完整而覆盖用户的新要求。

## 修改边界

保留原始题目、数据、代码、论文和真实结果。只在授权范围内修改；修改重要文件时保留原版本或建立可追溯版本。
