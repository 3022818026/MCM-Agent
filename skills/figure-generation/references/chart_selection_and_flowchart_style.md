# 图表选择、画布与流程图规范

本文件把图形选择与版面规则集中到一个按需参考中。先确定论证任务和数据结构，再选择图形；推荐比例只作为初始画布，不得为满足比例压缩数据、标签或图例。

## 1. 选择顺序

依次判断：数据类型与维度、样本量与量级、时间/空间/网络结构、是否含误差或区间、是否为拟合/预测/优化结果、论文中的单一论证句、最终插入尺寸。优先级固定为：事实正确、结论可读、布局合理、视觉美观。

## 2. 常用图形与初始比例

| 论证任务 | 优先图形 | 初始宽高比 |
| --- | --- | --- |
| 单维类别数量或指标 | 垂直柱状图 | 4:3 |
| 长类别名称、排序或重要度 | 水平条形图、龙卷风图 | 3:2 |
| 多组量化对比与误差 | 分组柱状图、点区间图；构成才用堆叠柱 | 5:4 |
| 单总体少类别构成 | 饼图或排序条形图；精确比较优先条形图 | 1:1 或 4:3 |
| 多层构成 | 环形图、旭日图；层级不清时改堆叠条形 | 1:1 |
| 单变量分布 | 直方图、ECDF、密度图 | 5:4 或 4:3 |
| 多类别分布 | 箱线图、小提琴图、ECDF | 5:4 |
| 双变量关系或预测校验 | 散点图加拟合/参考线 | 1:1 |
| 多变量相关 | 相关热力图、必要时散点矩阵 | 1:1 |
| 概率分布校验 | QQ图、PP图 | 1:1 |
| 连续时间趋势、动力学或灵敏度 | 折线图、区间带、相轨迹图 | 8:5；高密度时16:9 |
| 空间点位、路径、选址 | 点位图、路径图 | 1:1或真实空间比例 |
| 地理场、温度场、浓度场 | 区域填色、等值线、热力图 | 保持真实地理比例，常用4:3 |
| 矩阵、混淆矩阵、邻接矩阵 | 矩阵热力图 | 1:1 |
| 网络与层次结构 | 网络图、树状图 | 1:1；横向树4:3 |
| 多目标优化 | 帕累托前沿 | 1:1 |
| 收益—风险、成本—效益 | 四象限图、散点决策图 | 1:1 |
| 多方案多维指标 | 平行坐标；指标少且同向同尺度时可用雷达图 | 16:9或1:1 |
| 收敛、复杂度、规模效率 | 收敛曲线、复杂度折线 | 8:5或4:3 |
| 分类模型 | ROC、PR、校准图；按类别不平衡选择主图 | 1:1 |
| 残差与误差 | 残差散点、误差分布、QQ图 | 5:4 |
| 信号与频谱 | 波形图、频谱图 | 8:5 |
| 状态转移或仿真过程 | 状态转移图、状态时序图 | 1:1或8:5 |

不机械套用表格。存在配对、尾部风险、近重合曲线或不确定性时，执行`../../shared-references/common_figure_requirements.md`中的比较图闭环，优先展示逐对象差值、区间或分布。

## 3. 画布、坐标与图例

- 根据最终插入尺寸、标签长度、曲线密度和图例数量调整画布；优先增加必要的纵向空间，不制造大面积顶部空白。
- 坐标范围贴合数据。不得为容纳图例大幅扩张坐标或压缩数据主体；截断轴、对数轴和局部放大必须明确标注并保留完整尺度背景。
- 图例放在不遮挡数据、拟合线、误差棒、区间、极值和标注的稀疏区域。左上角仅在确实空闲时优先；图内无合适位置时使用紧凑的图外多列图例。
- 图例需要多少空间就增加多少空间；若图例过多，优先精简类别、分图或改为直接标注。
- 图形类型、宽高比和图例位置在渲染后根据实际数据复核，不把推荐值写成固定模板。

## 4. 普通图视觉边界

- 使用白底、黑色文字和坐标、浅灰辅助网格、克制的深色高对比配色；类别颜色兼顾色觉缺陷和黑白打印。
- 禁止无意义渐变、卡通元素、装饰图标、AI信息图式排版和纯装饰3D。只有数据确含第三维或层级且二维表达会丢失关键信息时才采用3D，并检查遮挡、透视和数值误读。
- 图内不重复Word题注中的完整图号和图题；保留必要的面板标签、单位、图例和短说明。

## 5. 流程图强制风格

问题分析、算法、数据处理、技术路线、模型建立、求解、仿真和优化流程图统一使用：纯白背景、黑色文字、无填充的细黑矩形、黑色直线实心箭头。不得使用彩色节点、圆角、渐变、阴影、3D、图标、Emoji、插画、纹理或PPT/信息图风格。

- 节点采用同级等宽等高的标准矩形；文字居中，每个节点只写一个“动词+对象”的关键步骤，通常4—10个中文字，尽量不超过两行。
- 字体采用中文论文正文风格，中文优先宋体类衬线字体，英文和数字优先Times New Roman；字号、线宽和间距统一。
- 步骤线性且数量允许时，默认使用3列蛇形布局：第一行左至右，下一行右至左，交替向下。3个步骤可单行；4—6个步骤用两行；7—9个步骤优先3×3；10—12个步骤优先3×4。
- 存在分支、回路、并行或汇合时，逻辑正确性高于蛇形外观；仍使用正交直线连接，并通过布局消除交叉，不把真实决策结构硬改成线性顺序。
- 列中心、行中心、节点尺寸、水平/垂直间距和箭头长度严格对齐。箭头从节点边缘中心出发，不穿过节点、不交叉、不使用曲线或无必要斜线。
- 3列多行流程通常从2:1至2.5:1宽版画布起步，再按节点文字和行数调整；不得压扁节点或留下巨大空白。
- 图号和图题由Word/LaTeX生成时不写入图片；必须内置时置于图下居中，且不加标题框。

## 6. 输出前检查

普通图逐项检查图形—数据匹配、比例、数据区域利用、图例遮挡、空白、坐标范围、标签、字体、单位、不确定性和论文尺寸可读性。流程图另检查黑白细框、无圆角/填充/装饰、节点统一、几何对齐、正交箭头、无交叉、阅读顺序、文字压缩和非信息图风格。任一关键项失败时修改源代码并重新渲染，不用后期涂改掩盖问题。
