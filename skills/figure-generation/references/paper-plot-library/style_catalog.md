# 导入论文绘图库：风格目录与使用门禁

## 定位

本目录导入自用户提供的paper-plot-skills-main。assets/paper-plot-library/originals/和reproductions/仅用于内部风格比对，不得作为新赛题的结果图、不得替换真实数据图，也不得直接放入竞赛论文。source-guides/和source-scripts/保留原始参考材料；其中的示例数据、绝对输出路径、300dpi导出和外部LaTeX依赖均不适合作为新项目默认设置。

实际调用优先使用scripts/paper-plot-library/paper_plot_library.py中的可复用函数。该库继承原图的强对比、层次清晰、标签突出与适度纹理风格，同时服从common_figure_requirements.md和user_delivery_contract.md的真实性、可读性与比较闭环要求。

## 环境与调用

MATLAB用于数据分析、建模、求解和结果导出；Python使用已锁定的CSV、Excel或结果注册表数据绘图。不得在绘图代码内改写核心数值。Python环境至少需要numpy和matplotlib，不要求LaTeX、SciPy或在线字体。

调用时将paper-plot-library目录加入Python路径，再从paper_plot_library导入对应函数。每次调用必须：

1. 先说明图要支撑的正文结论、数据源和结果ID；
2. 以实际Word插入尺寸设置font_size为12至18，而非固定字号；
3. 用save_paper_figure导出300—600dpi的PNG，通常从400dpi起；
4. 给出“图号+图题”的Word图注；
5. 在实际缩放尺寸下检查数字、图例、置信区间、零线和核心差异；不通过则改图形类型。

## 模板映射

| 论证任务 | 可调用函数 | 可借鉴的原始脚本 | 使用条件 | 不可用情形 |
|---|---|---|---|---|
| 同一对象上的基线—方案配对比较 | paired_delta_bar | bar_memevolve.py | 两组值严格配对，差值是正文核心 | 差异接近零、类别过多或横轴不是配对对象 |
| 2—4个方法在少量类别上的绝对比较 | grouped_bar | bar_spice.py | 同尺度、柱状图从零起、必要时用细斜线突出焦点方法 | 大量方法/类别、需要显示逐样本差异 |
| 时序或迭代趋势及其区间 | line_with_band | line_selfdistill.py、line_aime.py | 区间有重复试验、bootstrap或情景模拟来源 | 用平滑或伪造阴影带掩盖真实波动 |
| 局部结构决定结论 | line_with_inset | line_loss_inset.py | 主图保留全量范围，放大区与来源框明确连线 | 仅为放大微小差异或制造视觉冲击 |
| 统一方向与尺度的3—8个指标 | radar_comparison | radar_dora.py | 明确范围、指标方向、归一化规则，原始数值另列表 | 用面积暗示综合优越性或不同量纲直接比较 |
| 横轴有真实大段无观测区间的散点关系 | broken_axis_scatter | scatter_break.py | 明示左右范围、断裂符号与共享纵轴 | 用断轴夸大细小效果或无真实结构空档 |
| 已计算的PCA、t-SNE或UMAP二维坐标 | clustered_scatter | scatter_tsne.py | 图仅展示结构，方法、参数、随机流另行登记 | 把视觉聚类当作显著性或分类有效性证据 |
| 大量同量纲结果的模式浏览 | heat_value_table | classwise_iou_table.py | 附录、横向页面或二维参数结构，颜色和数值同时存在 | 正文需要精确逐项比较时，应改为三线表 |

## 颜色和版式继承

- 白色背景、深色坐标轴、浅灰虚线网格、深色高对比类别色和适度留白。
- 默认不使用图内长标题；正式标题交给Word图下注释。不得使用蓝色标题、emoji或未经验证的装饰文字。
- 斜线填充只用于黑白辅助区分，保持较细、稀疏，且不得遮挡柱顶数值、百分比或置信区间。
- 不固定2×2布局；默认每张PNG只服务一条可独立引用的论证结论。
- 原库中的3D、彩虹色等视觉语言只在数据结构、读者任务和黑白可读性均通过时采用；不以“复现风格”为由牺牲事实表达。

## 比较图选择

当两方案在同一批样本、情景或年份上的曲线近乎重合时，不得只改颜色或线宽。至少生成逐样本差值分布、配对散点或斜率图候选；最终图要同时表达零基准、区间、胜率或尾部差异，并如实保留“差异很小或证据不足”的结论。候选图和最终选择理由登记到图表清单。

## 图像复现边界

仅在用户明确要求“按某张参考图复现版式”时，才使用source-guides/reproduction_guide.md。复现的是版式与视觉语法，不是原图像素、原数据或原结论。若输入为他人论文图，必须以当前项目的真实数据重新绘制，并避免复制可识别的原始图形元素。

## 扩展模板与论证任务

以下模板沿用同一套白底、深色高对比配色、浅灰虚线网格、细描边、克制纹理和图内无长标题的风格。它们是按数据结构和论证任务添加的，不要求每篇论文全部使用。

| 论证任务 | 可调用函数 | 已有实践或典型场景 | 必要条件 | 不应使用的情形 |
|---|---|---|---|---|
| 方案、年度或区域的组成结构 | stacked_composition_bar | 2024C作物种植结构 | 成分非负且总量有解释 | 成分过多、精确差异才是重点 |
| 情景模拟下的年度均值和区间 | annual_risk_trend | 2024C年度净收益及90%区间 | 有逐情景或重复试验结果 | 区间没有明确来源 |
| 少量方案的收益、误差或风险分布 | risk_boxplot | 2024C样本外累计收益比较 | 每个方案有足够独立或情景样本 | 仅有一个汇总数 |
| 下侧风险、阈值达标率或分布支配 | ecdf_risk_comparison | 2024C累计收益ECDF | 指标可排序，尾部含义明确 | 曲线近乎重合却不补差分证据 |
| 同一批对象上的微小方案差异 | paired_difference_distribution | 情景收益差、重复试验差 | 数据严格配对 | 两组样本独立或配对关系不清 |
| 变量间相关或对称判断矩阵 | correlation_heatmap | 2024C参数相关结构 | 数值范围、方向和矩阵语义明确 | 用颜色替代数值或非对称矩阵被误称相关 |
| 正负影响、替代互补、系数变化 | diverging_bar | 2024C跨作物关系强度 | 零点有实际含义 | 组成占比或全部非负比较 |
| 预测值与真实值的一致性 | observed_predicted_scatter | 回归、仿真重构、机器学习验证 | 同口径观测与预测成对存在 | 无外部或留出验证数据却宣称泛化 |
| 拟合后的系统误差检查 | residual_scatter | 回归和机理模型诊断 | 残差与拟合值已计算 | 只为展示好看散点而隐藏异常 |
| 参数上下界的局部敏感性 | sensitivity_tornado | 阈值、权重、成本、风险参数 | 基准值与扰动范围已说明 | 交互作用主导却只做单因素结论 |
| 连续参数扫描或稳健区间 | sensitivity_curve | 步长、权重、惩罚、阈值扫描 | 参数按有序合理区间取值 | 试验点很少且插值被误读为连续规律 |
| 二维多目标权衡与折中解 | pareto_front | 收益—风险、成本—效果 | 明确两个目标方向与非支配定义 | 将加权单目标解伪称Pareto前沿 |
| 特征重要度或方案排序 | lollipop_ranking | SHAP汇总、指标排序、贡献度 | 排序方向和单位明确 | 类别过多或正负效应需分开解释 |
| 有真实坐标含义的空间分布 | spatial_bubble | 地块、站点、区域、网络节点位置 | x、y为真实空间或嵌入坐标 | 用无序编号制造空间暗示 |
| 跨问关系或复杂算法步骤 | process_flowchart | 建模技术路线、情景生成、迭代求解 | 节点5—10个且正文不重复图中步骤 | 简单流程、长段文字或超过10节点 |

当用户给出新题时，先按本表选择2—4个有统计意义的候选表达，再以结论可见性、事实忠实度、区间表达、最终版面和黑白可读性选择最终图。若真实差异很小，最终图必须忠实反映证据不足，不能通过坐标、断轴、放大图或配色夸大。
